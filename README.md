# Notion Playlist Player

A lightweight, embeddable audio and video playlist player for Notion pages.

## Features

- YouTube, direct audio URLs, and local audio previews
- Sequential and shuffle playback
- Optional playlist loop and 2, 3, or 5 second fade-out/fade-in transitions
- Drag-and-drop ordering and duplicate tracks
- Full multi-line titles, total playlist duration, and a live YouTube backdrop
- Standalone page-specific links
- Optional Notion automation with cross-device, page-specific auto-save for the playlist, volume, playback order, loop, and transition settings
- Fresh playback position on every page load

## Deployment

The app is ready for Vercel. Standalone mode requires no environment variables.

For automatic page-specific embeds and cross-device playlist storage, see `AUTOMATION.md`.
