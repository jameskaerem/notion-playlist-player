# Notion Playlist Player

A lightweight, embeddable audio and video playlist player for Notion pages.

## Features

- YouTube and direct audio URL support
- Local audio file preview
- Sequential and shuffle playback
- Optional playlist loop
- Fade-out transitions
- Drag-and-drop track ordering
- Duplicate track support
- Shareable playlist configuration links
- Fresh playback state on every page load

## Deployment

This is a static web app ready to deploy on Vercel or another static hosting platform.

## Notes

Local files are available only during the current browser session. Use hosted audio URLs for reusable playlist links.
